# Changelog

All notable changes to the Jigsaw desktop builds are documented here.
Version numbers follow the app version from `pubspec.yaml` (`x.y.z+build`).

## [1.2.1+18] — 2026-10-23

First public desktop release.

- Linux x64, Windows x64, macOS Apple Silicon and macOS Intel builds.
- Obfuscated AOT release binaries with stripped native runners.
- SHA-256 checksums and a `latest.json` manifest for every release.
- Shared game features: leveled puzzles, daily and event puzzles, accounts and
  progress sync, leaderboard, achievements, hints, store, settings and support.
- Desktop-specific Razorpay checkout via WebView.
- Desktop window title, app icon and 1280×800 default window.
