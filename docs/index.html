Linux

Extract the archive and run ./jigsaw. Requires GTK 3, libsecret and WebKitGTK 4.1. Install commands are in the README.

Windows

Extract the ZIP, then run jigsaw.exe. SmartScreen may ask for confirmation because the build is not commercially signed.

macOS

Drag Jigsaw into Applications. On first launch, allow it under System Settings → Privacy & Security. Builds are not notarized.
